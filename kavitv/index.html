Setup

Short version, per app. The playlist URL is all you need; the guide URL adds what's on.

Flix Pro Player

  1. Open the Flix Pro portal or app.
  2. Add a new playlist and paste the M3U URL.
  3. Add the XMLTV URL as the EPG source.

TiviMate

  1. Settings → Playlists → Add playlist → M3U playlist.
  2. Paste the M3U URL, name it KaviTV.
  3. Add the XMLTV URL as the EPG source for the playlist.

IPTV Smarters

  1. Choose "Login with M3U URL" (not Xtream).
  2. Paste the M3U URL and name the playlist KaviTV.
  3. The app pulls the guide from the M3U's tvg-url automatically.

Emby Live TV

  1. Dashboard → Live TV → Add tuner device → M3U.
  2. Paste the M3U URL.
  3. Add a guide provider → XMLTV, paste the XMLTV URL.
One honest note: KaviTV plays what's currently airing — you tune in, not on demand. Streams resolve through Seth's home server, so the channels work when you're on Seth's network.
